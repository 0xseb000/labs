# IPTables Firewall — Securing Port 5000

## Task

The security team identified that port `5000` (Apache) is open to everyone on all app hosts with no firewall in place. The goal is to restrict access to port 5000 so that only the LBR host can reach it.

**Requirements:**
1. Install `iptables` and all dependencies on each app host
2. Block incoming port `5000` for everyone except the LBR host
3. Rules must persist after a system reboot

**Infrastructure:**
- App hosts: `stapp01`, `stapp02`, `stapp03` (CentOS 9)
- LBR host IP: `10.244.73.198`

---

## Solution

### Install iptables-services

While `iptables` itself may already be present, `iptables-services` (required for systemd-based persistence) is not installed by default.

```bash
sudo yum install -y iptables-services
```

---

### Enable and start iptables

```bash
sudo systemctl enable iptables
sudo systemctl start iptables
```

---

### Configure firewall rules

Added the following rules to `/etc/sysconfig/iptables`. Order matters, iptables processes rules top-down (first match wins).

```
-A INPUT -p tcp -m state --state NEW -m tcp --dport 5000 -s 10.244.73.198 -j ACCEPT
-A INPUT -p tcp -m state --state NEW -m tcp --dport 5000 -j DROP
```

**Logic:**
- Rule 1: Allow the LBR host (`10.244.73.198`) to access port 5000
- Rule 2: Drop all other incoming connections on port 5000

---

### Save rules for persistence

```bash
sudo iptables-save | sudo tee /etc/sysconfig/iptables
```

> **Why `tee` instead of `>`?**  
> The `>` redirect runs without `sudo` privileges and causes `Permission denied`. Using `tee` ensures the write operation itself runs with elevated rights.

---

### Verification

**Check saved rules:**
```bash
sudo cat /etc/sysconfig/iptables
```

**Check service status:**
```bash
sudo systemctl status iptables
```

**Test connectivity from LBR host:**
```bash
curl http://<app-host-ip>:5000
```
-> Should return a response
-> From any other host, the connection should be blocked

---

## Result

Final `/etc/sysconfig/iptables` configuration:

```
# Generated by iptables-save
*filter
:INPUT ACCEPT [0:0]
:FORWARD ACCEPT [0:0]
:OUTPUT ACCEPT [217:22136]
-A INPUT -m state --state RELATED,ESTABLISHED -j ACCEPT
-A INPUT -p icmp -j ACCEPT
-A INPUT -i lo -j ACCEPT
-A INPUT -p tcp -m state --state NEW -m tcp --dport 22 -j ACCEPT
-A INPUT -s 10.244.73.198/32 -p tcp -m state --state NEW -m tcp --dport 5000 -j ACCEPT
-A INPUT -p tcp -m state --state NEW -m tcp --dport 5000 -j DROP
-A INPUT -j REJECT --reject-with icmp-host-prohibited
-A FORWARD -j REJECT --reject-with icmp-host-prohibited
COMMIT
```

All three app hosts (`stapp01`, `stapp02`, `stapp03`) are reachable via the LBR host on port 5000. Direct connections from any other host are blocked. Rules persist across reboots.
